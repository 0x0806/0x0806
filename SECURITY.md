# Security Policy

This repository only contains my GitHub profile README and its automation.

If you find a security problem in the workflows or scripts here (for example a
way to abuse the Actions configuration), please report it privately through
GitHub's **Report a vulnerability** option on the Security tab, or via
[my portfolio](https://0x0806.me). Please don't open a public issue.

For vulnerabilities in my other projects, use the same channel on the relevant repository.
